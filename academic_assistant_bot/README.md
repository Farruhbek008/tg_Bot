# 🎓 Персональный учебный ассистент студента (HEMIS + Мульти-ИИ: Groq, Gemini, G4F)

Телеграм-бот для автоматизации учебного процесса в системе **HEMIS** (`student.fstu.uz` / `my.hemis.uz`) с встроенным мульти-модельным ИИ-тьютором, полной русификацией расписания, предметов, заданий и учебных ресурсов.

## ✨ Основные возможности

1. **🤖 Выбор ИИ-провайдера и моделей прямо в боте (`/model` или кнопка «⚙️ Выбор ИИ-модели»):**
   - **⚡ Groq Cloud** — `Llama 3.3 70B Versatile`, `GPT-OSS 120B`, `GPT-OSS 20B`, `DeepSeek R1 Distill 70B`, `Qwen 3 32B`, `Llama 3.1 8B Instant`.
   - **✨ Google Gemini** — `Gemini 2.5 Flash`, `Gemini 2.5 Pro`, `Gemini 2.5 Flash-Lite`, `Gemini 2.0 Flash`.
   - **🆓 G4F / GPT4Free (Бесплатно без ключей)** — `GPT-4o`, `GPT-4o Mini`, `DeepSeek R1`, `DeepSeek V3`, `Claude 3.7 Sonnet`, `Qwen 2.5 Coder 32B`, `Llama 3.3 70B`, `Gemini 2.5 Flash (Free)`.
   - Возможность указать персональный API-ключ для Groq или Gemini прямо через интерфейс бота.
   - Сохранение выбранной модели и семестра в базе данных SQLite (`user_settings`).

2. **🇷🇺 100% русификация данных HEMIS и интерфейса (`services/translator.py`):**
   - Автоматический перевод узбекских названий дисциплин, типов занятий (*Ma'ruza → Лекция*, *Amaliy → Практическое занятие*, *Laboratoriya → Лабораторная работа*, *Mustaqil ta'lim → Самостоятельная работа*), статусов заданий, номеров корпусов и аудиторий.
   - Автоматический перевод произвольных узбекских тем лекций, названий файлов и описаний заданий с кэшированием в SQLite (`translation_cache`).

3. **📅 Расписание занятий (`/schedule`):**
   - Расписание на сегодня, завтра и по неделям с навигацией вперёд/назад.

4. **📝 Задания и дедлайны (`/assignments`):**
   - Список заданий выбранного семестра со статусами и сроками сдачи.
   - Мгновенное скачивание прикреплённых файлов заданий с локальным кэшированием и отправкой по `file_id`.
   - Разбор условия и содержимого PDF/DOCX файла задания с выбранной моделью ИИ в один клик.

5. **📚 Учебные ресурсы и успеваемость (`/resources`, `/performance`):**
   - Фильтрация материалов по категориям: **Все**, **Лекции**, **Практика**, **Лабораторные**, **СРС**.
   - Кнопка **«🤖 Разобрать этот материал с ИИ-тьютором»** при скачивании любого учебного файла (автоматическое составление конспекта по файлу).
   - Сводка текущего GPA, набранных баллов и часов пропусков (по уважительной и без уважительной причины).

6. **⏰ Умные напоминания (`/remind`) и 📓 Заметки (`/notes`):**
   - Распознавание естественных фраз на русском языке (*«напомни завтра в 09:30 сдать лабораторную»*, *«через 30 минут повторить билеты»*).
   - Сохранение ответов ИИ-тьютора в личные конспекты одним нажатием.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка `.env`
Проверьте файл `.env` в корне проекта:
```env
BOT_TOKEN=ваш_токен_телеграм_бота
DEFAULT_AI_PROVIDER=groq
GROQ_API_KEY=gsk_...
GEMINI_API_KEY=AIza...
G4F_MODEL=gpt-4o
HEMIS_BASE_URL=https://student.fstu.uz
HEMIS_LOGIN=ваш_логин_hemis
HEMIS_PASSWORD=ваш_пароль_hemis
TIMEZONE=Asia/Tashkent
```

### 3. Запуск бота
```bash
python bot.py
```

Или через Docker Compose:
```bash
docker compose up -d --build
```
